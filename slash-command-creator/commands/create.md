# Create Slash Command

This command guides you through creating a custom slash command using the available templates.

Step 1: Identify the tool (Gemini, Claude, or Codex).
Step 2: Choose the template.
Step 3: Create the file in the correct location.

Reference the `SKILL.md` or `assets/` folder in this plugin for templates.
